# Airport Management System

## Technologies Used
- **Back-End**: Java, Spring Boot
- **Front-End**: Angular 14
- **Database**: MySQL
- **DevOps**: Docker
- **Cloud Deployment**: AWS EC2

## Features
- Flight scheduling and gate management
- Staff and user management system
- Admin dashboard for operational oversight
- Secure login system with user roles
- Microservices architecture for modularity and scalability

## Architecture
The system is split into multiple services:
- **User Service** – handles authentication and user management
- **Flight Service** – manages flight data and scheduling
- **Gate Service** – assigns gates and tracks usage
- **Notification Service** – sends alerts to admins and staff

## Deployment
- Dockerized services for easy deployment
- Hosted on AWS EC2 virtual machines
- Configuration via Docker Compose

## How to Run Locally
1. Clone the repository
2. Run backend services via Docker
3. Launch Angular frontend with `ng serve`
4. Access app at `http://localhost:4200`
